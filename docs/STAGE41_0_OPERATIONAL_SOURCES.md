# Stage 41.0 — Operational source wave

## Sources

### DSNS Ukraine Telegram

Added `dsns_telegram` to the public Telegram OSINT monitor as an official source.

The first production pull succeeded.

Because DSNS sometimes publishes national multi-region roundups, a source-specific strict segment gate was added:

- geography and fire/explosion vocabulary must occur in the same line/sentence segment;
- a region name elsewhere in a long national roundup is not enough.

The five links generated by the first broad-roundup pass were immediately marked `geo_rejected` and retained only for audit.

### RainViewer

Public endpoint:

`https://api.rainviewer.com/public/weather-maps.json`

GeoWatch stores the radar frame timeline in `rainviewer_frames`.

The public endpoint exposes only a short recent history, therefore GeoWatch polls every 10 minutes and keeps frame metadata for 14 days.

For an event, a frame is matched within ±20 minutes.

A coordinate-centred radar tile URL is stored when a matching frame exists.

RainViewer is weather context only:

`independent_for_corroboration = false`

### EUMETSAT MTG Lightning Imager

Collection:

`EO:EUM:DAT:0691`

Product:

`LI Lightning Flashes / MTILI2LFL`

The EUMETSAT OpenSearch catalogue is queried without credentials and product metadata is archived for 14 days.

On the first production run, 137 NRT LI products were backfilled for the previous 24 hours.

At this stage the system stores temporal product coverage only. It does not claim local lightning.

Field:

`lightning_local_signal = not_extracted`

The source therefore remains:

`independent_for_corroboration = false`

until actual flash coordinates are extracted from the NetCDF product.

Downloading/parsing the underlying LI NetCDF requires EUMETSAT Data Store credentials and is a follow-up sub-stage.

## Environment Context

New tables:

- `rainviewer_frames`
- `eumetsat_li_products`
- `event_environment_context`

New function:

`firewatch-environment-context`

Schedule:

`4,14,24,34,44,54 * * * *`

The function:

1. archives RainViewer frames;
2. archives EUMETSAT LI NRT product metadata;
3. associates recent fire events with the closest radar frame;
4. associates events with LI temporal product coverage;
5. stores only contextual status, not causal conclusions.

## Deep OSINT

`firewatch_deep_osint()` now contains:

`environment_context`

Client output adds:

`🌦 Погодный / грозовой контекст`

The wording distinguishes:

- radar frame availability;
- radar history unavailable;
- MTG LI product coverage;
- local lightning not yet extracted.

## Watchdog

Watchdog monitors the 10-minute environment process.

New conditions:

- `ENV_CONTEXT_STALE` after 30 minutes;
- `ENV_CONTEXT_ERROR` on total failure.

## Security

All three new tables are backend-only with RLS enabled and no anon/authenticated grants.

SECURITY DEFINER RPC execution is explicitly revoked from PUBLIC/anon/authenticated and granted only to service_role.
